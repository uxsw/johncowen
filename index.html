02

How I work

Involved from the first sketchy ideas in Figma through to front-end implementation, alongside engineers, PMs and user researchers.

  1. 2.1

    Easy to use, hard to mess up.

    User journeys designed for both the humans on the surface and the technology underneath. Complexity gets untangled behind the scenes so it never has to be explained on the screen.

  2. 2.2

    Components from the first sketch.

    I design with components in mind so things are easy to build, scale and keep tidy. I’ve built design systems from nothing, more than once, and increasingly build them so both people and AI-assisted tooling can work from the same source of truth.

  3. 2.3

    I ship the front end.

    Production CSS and front-end contributions, not just handover files. It keeps the design honest and the product fast, accessible and that bit nicer to use.

  4. 2.4

    Low-energy by design.

    Sustainable design is part of the brief now. On my current project I developed a low-energy colour palette and sit on the client’s sustainable design working group. This page’s dark mode is that thinking in practice.
